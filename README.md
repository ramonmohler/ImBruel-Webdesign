# Im Brüel – Prototyp E „Hell & zugewandt“

Statischer Klick-Prototyp der Startseite (GSAP-Animationen).

- `index.html` – die Seite
- `assets/` – CSS, JavaScript und Bilder
- `.nojekyll` – GitHub Pages liefert die Dateien unverändert aus

Online stellen: **Settings → Pages → Deploy from a branch → main / (root) → Save**.
Lokal ansehen: `python3 -m http.server 8765` und http://localhost:8765 öffnen.
